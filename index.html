This is a planning principle, not a target.

Sharing this isn't about pushing numbers onto you. We're using your input to set a principle for how many leads we should request from each channel — and how hard we need to lean on outbound sales to fill the rest.

So don't anchor on current targets. Think about your realistic direct-approach capacity, and tell us purely how many leads and SQLs you actually need to work your patch well. We build the plan around that — not the other way round.
